## Five example records (paraphrased)

1. E2E specs fail locally before the first assertion because an auth env var is missing → **gotcha**
2. We chose SQLite over a hosted DB for the registry because it is single-user → **decision**
3. Idea notes cannot be edited or deleted; every idea write is permanent → **invariant**
4. If the scheduled job keeps parking items, the review file will hit its guard → **risk**
5. A shared ticket label can span two unrelated undertakings; check the branch name → **gotcha**
