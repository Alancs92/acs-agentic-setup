Claude Code usage

Stored data is UTC. Every date, hour and timestamp in stats.json is UTC; the collector records its own zone as an IANA name. Hour-resolution panels (calendar, prompts/day, hour × weekday, sessions) are converted to UTC for display. Day-resolution panels (tokens, model mix) stay on UTC days — a UTC day straddles two local days, so re-labelling it local would be a lie. Conversion is exact only for whole-hour zones.
